# Live on Vercel

## [portfolio-mjwinnr08-aylamichs-projects.vercel.app](https://portfolio-mjwinnr08-aylamichs-projects.vercel.app/)

---

A personal portfolio with a minimalist look, built to feel like a resume: simple, readable, and focused on what actually matters.

---

## Built with

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Bootstrap 5](https://getbootstrap.com/)
- [Framer Motion](https://www.framer.com/motion/)

---

## Running locally

```bash
git clone https://github.com/aylamich/portfolio-cv.git
cd portfolio-cv
npm install
npm run dev
```
